Multi-Provider AI
Pilih provider AI (Groq atau Google Gemini), model yang digunakan, dan kelola API Key.

Mode Eksekusi AI Utama

Tentukan provider yang diprioritaskan untuk menyusun narasi akademik dan konsultasi metodologi.

1. Groq AI Engine (LPU Ultra Cepat & Anti-Limit)

Sangat direkomendasikan untuk pelatihan karena kuota responsif dan bebas rate-limit 20 req/menit.

Belum Terpasang

Dapatkan API key gratis tanpa batas di Groq Console.

2. Google Gemini API (Google AI Studio)

Model resmi Google AI Studio untuk penalaran akademik berstandar APA 7th.

Belum Terpasang

Dapatkan API key gratis di Google AI Studio.

Local Storage Mode

Aplikasi saat ini berjalan secara optimal menggunakan browser storage lokal dan file dataset bawaan. Jika Anda ingin menghubungkan Supabase kustom, Anda dapat mengatur NEXT_PUBLIC_SUPABASE_URL dan NEXT_PUBLIC_SUPABASE_ANON_KEY di file .env.local saat deploy ke Vercel.
